# Nozibusiso Bhebhe Portfolio

This is a standalone portfolio website for Nozibusiso Bhebhe.

## Folder structure

index.html

assets/
  css/
    style.css
  js/
    script.js
    three-hero.js
  images/
    nozibusiso-hero.jpg
  Nozibusiso_Bhebhe_CV_2026.pdf

## GitHub

Upload the contents of this folder to the root of a new GitHub repository.

The file called index.html must sit at the repository root.

## Hosting

The site is a static website and can be hosted through GitHub Pages, Render, Netlify or another static hosting service.

The 3D hero uses Three.js from a public CDN, so the site needs an internet connection for the 3D network to load.
